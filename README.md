# scRNA-seq Analysis of iPSC-Derived Dopaminergic Neurons

This project analyzes single cell RNA sequencing data from iPSC-derived dopaminergic neurons using Scanpy, including Leiden clustering to identify distinct cell populations.

## Methods
- Preprocessing and quality control of scRNA-seq data
- Dimensionality reduction
- Leiden clustering for cell population identification
- Analysis performed in Scanpy (Python)

## Status
Published in a high school research journal.
